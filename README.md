Turn your photos into GTA 6-style key art: a fully offline static web app with 6 multi-panel layouts (including a 7-panel Mosaic and diagonal Slanted cuts), a pop-out hero, face-aware crops, 6 colour grades, striped retro-chrome 3D titles, role tags, a press quote, a gold seal, a billing block, and PNG export in all three post sizes (1920×1080, 1080×1350, 1080×1080). Everything runs in the browser from local files — photos never leave your machine.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Pick a layout, drop photos into the panels (upload your own or use the samples — double-click a sample to fill every panel), drag to position each photo, scroll to zoom, write the caption, and export.
